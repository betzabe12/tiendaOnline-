VISIÓN DEL PROYECTO

FashionCloud – Tienda de Ropa Online

1. Introducción
Nombre del proyecto: FashionCloud – Tienda de Ropa Online.
Propósito del documento:
El presente documento tiene como propósito explicar qué es FashionCloud, qué problemas resolverá, quiénes utilizarán el sistema y cuáles serán sus principales funcionalidades. También permitirá establecer una visión general de cómo estará organizado el proyecto.
Alcance:
FashionCloud será una tienda de ropa online que permitirá a los clientes consultar productos, ver sus precios y características, agregar prendas al carrito, realizar pedidos y elegir métodos de pago. Además, el administrador podrá gestionar productos, categorías, inventario, clientes y pedidos.
En esta primera versión no se incluirán aplicaciones móviles nativas, fabricación de ropa ni servicios de transporte propios.
Definiciones y acrónimos:
Término	Definición
E-commerce	Compra y venta de productos por Internet.
Cliente	Persona que utiliza la tienda para comprar ropa.
Administrador	Persona encargada de gestionar la tienda.
Catálogo	Lista de productos disponibles para la venta.
Carrito	Espacio donde se guardan los productos antes de comprar.
Stock	Cantidad disponible de un producto.
Pedido	Solicitud de compra realizada por un cliente.
Referencias:
Se considerarán conceptos de comercio electrónico, necesidades de una tienda de ropa y documentación de las tecnologías utilizadas para desarrollar el sistema.

2. Posicionamiento del negocio
Oportunidad de negocio:
Actualmente, muchas personas prefieren comprar ropa por Internet porque pueden consultar productos y realizar pedidos desde cualquier lugar. FashionCloud permitirá que una tienda de ropa llegue a más clientes y mejore la organización de sus ventas.
Declaración del problema:
Las ventas realizadas manualmente pueden provocar errores en los pedidos, dificultad para controlar el inventario y problemas para informar a los clientes sobre los productos disponibles. Por esta razón, se necesita un sistema que permita organizar y facilitar el proceso de compra y venta.
Declaración de la posición del producto:
FashionCloud será una plataforma de comercio electrónico dirigida a personas que desean comprar ropa y a administradores que necesitan gestionar una tienda online. Su principal característica será ofrecer una experiencia de compra sencilla y una administración organizada de productos, pedidos e inventario.

3. Descripción de las partes interesadas y usuarios
Parte interesada	Papel
Clientes	Consultan y compran productos.
Administrador	Gestiona productos, inventario y pedidos.
Propietario	Supervisa el negocio y sus ventas.
Desarrolladores	Diseñan, programan y mantienen el sistema.
Docente	Evalúa el cumplimiento del proyecto.
Usuario principales:
Los usuarios principales serán los clientes y administradores. Los clientes utilizarán el sistema para buscar ropa, realizar compras y consultar sus pedidos. Los administradores lo utilizarán para mantener actualizada la información de la tienda y controlar las ventas.
Entorno del usuario:
El sistema podrá utilizarse desde computadoras, tablets y celulares mediante un navegador web. Los clientes podrán acceder desde cualquier lugar con conexión a Internet, mientras que los administradores lo utilizarán para realizar las actividades de gestión del negocio.
Perfiles de las partes interesadas y usuarios:
•	Cliente: Busca comprar ropa de forma rápida, cómoda y segura. Necesita consultar precios, tallas, colores y disponibilidad.
•	Administrador: Busca mantener organizada la tienda. Necesita registrar productos, actualizar el stock y gestionar pedidos.
•	Propietario: Busca mejorar las ventas y tener mayor control sobre el negocio.
•	Desarrollador: Busca construir un sistema funcional, seguro y fácil de mantener.
•	Docente: Busca verificar que el proyecto cumpla con los requisitos establecidos.

4. Características del producto
Características principales:
FashionCloud contará con módulos que permitirán realizar las principales actividades de una tienda de ropa online:
•	Usuarios: Registro, inicio de sesión y gestión de datos.
•	Catálogo: Consulta de ropa, precios, tallas, colores y disponibilidad.
•	Carrito: Agregar, modificar y eliminar productos.
•	Pedidos: Registrar compras y consultar su estado.
•	Pagos: Seleccionar los métodos de pago disponibles.
•	Inventario: Controlar las cantidades de productos.
•	Administración: Gestionar productos, categorías, clientes y pedidos.
Requisitos funcionales:
El sistema deberá permitir registrar usuarios, consultar productos, buscar por categorías, agregar productos al carrito, realizar pedidos, seleccionar métodos de pago y consultar el estado de las compras. También deberá permitir al administrador gestionar productos, inventario y pedidos.
Requisitos no funcionales:
El sistema deberá ser fácil de usar, seguro, rápido y confiable. Además, deberá funcionar correctamente en navegadores web y adaptarse a diferentes dispositivos.
Restricciones:
El proyecto estará limitado por el tiempo, presupuesto y recursos disponibles. Se utilizarán las tecnologías definidas para su desarrollo y las funcionalidades deberán ajustarse al alcance establecido para la primera versión.
Conclusión
FashionCloud será una solución de comercio electrónico que permitirá facilitar la compra de ropa por Internet y mejorar la organización de una tienda. El sistema ayudará a los clientes a realizar sus compras de manera sencilla y a los administradores a gestionar productos, pedidos e inventario desde una misma plataforma.
